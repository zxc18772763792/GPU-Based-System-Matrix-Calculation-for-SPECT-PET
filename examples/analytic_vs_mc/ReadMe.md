# 解析模型 vs 蒙特卡洛：系统矩阵分量对比示例

用同一套 `Params_*.dat`，分别用解析模块（`PEGen_RayTracing_CircularHole` + `ScatterGen_RayTracing_CircularHole`）
和 `MCGen_MultiGPU` 计算系统矩阵，并按分量逐项比较：

| 解析模块 | MC 中对应的事件类别 |
|---|---|
| PE（光电，`PE_SysMat_*_v3.sysmat`） | `primary`：未在准直器中散射、首次相互作用就在本晶体中的事件 |
| 晶体散射（`Scatter_Crystal_SysMat_*`） | `xtalscatter`：先在其它晶体中相互作用、再在本晶体中沉积 |
| 准直器散射（`Scatter_Collimator_SysMat_*`） | `colscatter`：在准直器中发生过散射 |

`ScatterGen_RayTracing_CircularHole` 默认使用散射模型 v2（见下文“散射模型 v2”），`-model legacy` 为原来的内核。

## 几何

| | 140.5 keV（`tc99m`） | 511 keV（`511`） |
|---|---|---|
| 准直器 | W 板 60×6×60 mm，3×3 圆柱针孔，r = 0.75 mm，间距 12 mm | W 板 60×10×60 mm，孔同左 |
| 晶体 | 16×16 NaI，2.3×6×2.3 mm，间距 2.5 mm，FWHM 10 % | 16×16 LYSO，2.3×10×2.3 mm，间距 2.5 mm，FWHM 12 % |
| 晶体中心到准直器中心 | 30 mm | 30 mm |
| 视野 | 16×1×16 体素，2 mm，位于准直器前 40 mm 的平面 | 同左 |
| 能窗（`Param_Physics[4]=1`） | 126.46–154.56 keV（另算宽窗 60–200 keV） | 459.9–562.1 keV（另算宽窗 250–650 keV） |

准直板比所有 视野→晶体 视线都大，符合解析模型“光子从入射窗进入”的约定；MC 使用
`shield_outside_collimator = absorber`（板外全吸收），两者的屏蔽假设一致。

## 运行

```bash
# 单卡 GPU（默认 GPU 0，可用 GPU=1 指定）。先编译：
#   PEGen_RayTracing_CircularHole/bd, ScatterGen_RayTracing_CircularHole/bd, (cd MCGen_MultiGPU && make)
./run_example.sh tc99m gpu
./run_example.sh 511 gpu
SCATTER_MODEL=legacy ./run_example.sh tc99m gpu     # 原来的散射内核

# 没有 GPU：原始解析 CUDA 内核编译成 CPU 版本 (tools/analytic_cpu) + MCGen_CPU
(cd ../../MCGen_MultiGPU && make cpu)
./run_example.sh tc99m cpu
```

第三个参数为每体素历史数（默认 4×10⁶）。结果在 `run_<case>/`：`report.md`（表格）、`report.json`、
`flood.svg`（各分量对所有体素求和后的探测器图像，解析 vs MC）。

脚本依次运行：

1. `tools/make_demo_params.py` 生成参数；`wide/` 子目录为同一几何、宽能窗的参数。
2. 解析：`PEGen_CircularHole`，`ScatterGen_CircularHole -PE ... -components`（光电峰窗与宽窗各一次）。
3. MC，四组设置（都用 `source_sampling = center`，即体素中心点源，与解析内核一致）：
   * `mc_pe`：`physics = primary_pe`、参数文件系数、理想能窗 —— 与解析 PE 模型的物理完全相同；
   * `mc_single`：`physics = single_scatter`、参数文件系数 —— 至多一次康普顿散射、只记光电吸收，
     与解析散射模型 v2 的物理定义完全相同，是检验它的精确参考；
   * `mc_model`：光电 + 康普顿（不限散射次数），参数文件系数，无瑞利、无荧光；
   * `mc_full`：材料库截面 + 瑞利散射 + K 荧光 —— 真实物理。
4. `compare_components.py` 输出对比表。

表中各列：Σ 为全部矩阵元素之和；“ratio” 为 解析/MC（± 为 MC 统计误差）；“per-voxel ratio” 为逐体素灵敏度
比值的中位数与 5 %–95 % 范围；“shape TVD” = ½ Σ|A/ΣA − M/ΣM|，0 表示分布形状相同、1 表示完全不重叠；
“MC noise” 是 MC 统计涨落本身能造成的 TVD 上界。

## 散射模型 v2

一阶（单次康普顿）散射，在散射发生的整个体积上积分：

* **晶体散射**：入射束在散射晶体 j 中的康普顿相互作用（总概率 PE[j,v]·μ_C/μ_PE）分布到 j 内的一组点上
  （横向为 Gauss–Legendre 节点），按入射束到达每个点的透射率加权（准直器各层与孔、途经的晶体、j 自身；
  针孔光斑只照到 j 的一部分时也能反映）；从每个点出发，散射光子射向探测晶体 i 所有可见表面，表面按从
  散射点看去的等角度划分为小格（≤ 0.1 rad，每格用矩形的精确立体角，单独计算 Klein–Nishina 角分布、
  散射能量和能窗概率），计入在 j 自身、中间晶体中的衰减和在 i 中的光电吸收（靠近面边缘时穿过 i 的弦长
  线性降到 0，这些小格用 4×4 个子点平均）。
* **准直器散射**：散射点分布在钨中——每个孔周围的薄壳（不透明的准直板几乎全部散射都来自孔壁和孔口边缘；
  沿孔方向的节点向前、后表面加密，深度节点混合两种衰减尺度）加上板的其余部分（可穿透的准直板，如 511 keV；
  24×24 网格，每格用子点扣除孔与壳层所占部分，厚度方向 Gauss–Legendre）；入射与散射光子都按所有准直层
  及其孔精确计算透射（与 PEGen 相同的孔网格）。
* 散射能量处的系数：光电 ∝ E⁻³，康普顿 ∝ Klein–Nishina 总截面（与 MC 的 `params` 材料一致）。

精度参数（`S2_*` 宏，可用 `-D` 覆盖）及收敛检验见 `scatter.cu` 中 v2 段落的注释。

## 结果

本仓库开发环境没有 GPU：下表由 `./run_example.sh <case> cpu` 得到（解析 CUDA 内核编译为 CPU 版本，
内核代码与 GPU 相同；MC 每组 1.0×10⁹ 历史）。Σ 为全部矩阵元素之和（每个发射光子的计数 × 体素数）。

### 1. PE 模型

| `mc_pe`（与解析相同的物理） | 140.5 keV | 511 keV |
|---|---|---|
| 解析 / MC（总和） | 0.987 | 0.998 |
| 逐体素比值 中位数 [5 %, 95 %] | 0.990 [0.962, 1.005] | 0.998 [0.989, 1.006] |
| 形状 TVD（MC 噪声上界） | 0.011 (0.003) | 0.031 (0.031) |

140.5 keV 的 1.3 % 是解析内核的子单元离散（针孔半影）：把晶体子单元从 8×16×8 加密到 24×16×24 后为 0.996。
注意 MC 必须用参数文件的系数：若用材料库（含瑞利散射，`primary_pe` 下瑞利散射也会终止光子），
MC 会低 4.8 %（140.5 keV）/ 17 %（511 keV，主要是 10 mm 钨中的瑞利散射），这不是解析模型的误差。

### 2. 散射模型 v2 与一阶 MC（`mc_single`）：解析 / MC

| | 140.5 keV 光电峰窗 | 140.5 keV 宽窗 | 511 keV 光电峰窗 | 511 keV 宽窗 |
|---|---|---|---|---|
| 晶体散射 | 0.972 ± 0.018 | 0.977 ± 0.005 | 0.993 ± 0.026 | 0.993 ± 0.003 |
| 准直器散射 | 0.950 ± 0.041 | 0.953 ± 0.038 | 0.993 ± 0.002 | 1.000 ± 0.002 |
| 散射/主成分（解析 vs MC） | 0.0199 vs 0.0208 | 0.0679 vs 0.0688 | 0.2222 vs 0.2351 | 0.874 vs 0.874 |

晶体散射逐体素比值的 5 %–95 % 范围：140.5 keV [0.92, 1.02] / [0.94, 1.01]，511 keV [0.95, 1.04] / [0.98, 1.01]
（光电峰窗 / 宽窗）；探测器图像的形状 TVD 在 140.5 keV 为 0.06 / 0.05。140.5 keV 宽窗剩下的 −2 % 中约 1.3 %
来自 PE 矩阵（晶体散射按 PE[j,v] 归一，PE 内核在 140.5 keV 为 MC 的 0.987，见上节）。511 keV 光电峰窗的
散射/主成分比低 5 % 是主成分的原因：解析 PE 不含光电峰在窗内的比例（0.95），见第 3 节。准直器散射在
140.5 keV 的逐体素范围较宽（[0.55, 1.31]），主要是 MC 本身的噪声：这一分量里有一部分来自体素“看不穿”的孔
（光子从孔口边缘射入孔壁后散射），MC 的孔瞄准抽样不覆盖它们，以少量大权重事件出现（见下面的单体素检验）。

**修正历史**：上一版 v2 在宽窗中晶体散射低 5 %（0.950 / 0.952），光电峰窗 0.979 / 1.005，晶体散射形状 TVD
0.26 / 0.22（140.5 keV）。总量的 5 % 是几项较大误差部分抵消后的结果，单对晶体的偏差要大得多：

1. 散射点只按入射束在 j 内的衰减加权，没有计入准直器孔和相邻晶体的遮挡；针孔光斑只照到 j 的一部分时，
   单对晶体 −17 %…+27 %。现在按入射束到每个点的透射率加权。
2. 511 keV 宽窗的下沿（250 keV）正好对应约 90° 散射，即相邻晶体的方向。散射点靠近相邻晶体的面时，原来每个面
   最多分 8×8 块、每块跨 ±50°，只在块中心算能窗和角度，单个散射点 −53 %…+9 %。“精度参数加倍”时块数上限
   没有放开，所以看起来已收敛。现在表面按等角度划分为 ≤ 0.1 rad 的小格；光电峰窗中所有晶体散射都来自
   窗沿附近的角度（511 keV 约 27°），能量跨过窗沿的小格再用 3×3 子点平均能窗（511 keV 光电峰窗单体素：
   不平均时 0.963，平均后 0.991）。
3. 靠近面边缘时光子从侧面穿出，穿过 i 的弦长线性降到 0，只取格中心会高估（单格最多 1.6 倍）。这些格现在
   用 4×4 子点平均。
4. 散射点网格：横向改为 Gauss–Legendre 节点（最近邻 0.983 → 0.999，计算量不变），远处晶体至少 2 个点
   （1 个点时低 5–9 %）。
5. 准直板体网格只有 12×12（格宽可达 5 mm），每格按中心点决定是否扣除孔与壳层：网格 12 / 24 / 48 / 96 时
   板体散射为 1.98 / 1.81 / 1.89 / 1.88（×10⁻⁴，511 keV 单体素），不收敛。现在按 4×4 子点扣除，24 与 48
   相同（1.918e-4），默认 24×24；厚度方向改为 Gauss–Legendre。上一版准直器散射的面积分低约 3 %，与板体
   的 +5.5 % 部分抵消，所以 511 keV 宽窗的准直器散射当时看起来已经准确（0.998）。

作为对比，原来的内核（`-model legacy`）对同一参考：

| | 140.5 keV 光电峰窗 | 140.5 keV 宽窗 | 511 keV 光电峰窗 | 511 keV 宽窗 |
|---|---|---|---|---|
| 晶体散射 | 0.002 | 6.1 | 0 | 9.6 |
| 准直器散射 | 21.7 | 23.5 | 0.31 | 0.33 |
| 散射/主成分（解析 vs MC） | 0.138 vs 0.021 | 0.556 vs 0.069 | 0.065 vs 0.235 | 2.80 vs 0.87 |

原因：原内核把散射点固定在晶体中心/孔中心（平面阵列中晶体对之间 ≈ 90°，光电峰窗中晶体散射几乎为 0），
θ×φ 立体角把晶体厚度算了两次（每对晶体高 2.0–2.7 倍），没有散射晶体自吸收；准直器散射用孔中心的
“虚拟面积”且散射光子在钨中不衰减（140.5 keV 高约 20 倍），也没有板体内的散射（511 keV 低约 3 倍）。

**单独的检验**（`tools/analytic_cpu/scatter_cpu -skip … -holes …`，单体素/单孔几何）：

* 无孔钨板 + 单个 LYSO 晶体（511 keV）：v2 3.238e-7，独立的 numpy 体积分（加密至收敛）3.242e-7，相差 0.1 %
  （上一版 −2 %；最早远处晶体面只取中心射线的弦长时高 35 %）。
* 单孔（视野点偏轴 14°）+ 单晶体（140.5 keV）：独立的 numpy next-event 估计 2.05e-10，MC 2.20e-10 ± 6 %，
  v2 2.12e-10（上一版 2.29e-10）。其中一半散射来自打在孔口边缘、距前表面 < 0.3 mm、距孔壁 < 0.08 mm 的光子；
  v2 沿孔方向的节点在两端加密正是为此（加密前只有参考值的 45 %）。
* 511 keV 示例中一个偏心体素（宽窗，MC 1×10⁸ 历史，记录每个晶体散射事件的散射晶体与探测晶体）：
  晶体散射 0.990（上一版 0.953）；按晶体对偏移分组，主要偏移 0.97–1.00，较远偏移 0.96–1.02（MC 统计误差
  2–4 %），上一版对角方向 (2,2)、(3,3) 低 13–17 %。单个散射点与独立的 numpy 面积分相差 ≤ 0.6 %
  （上一版 −53 %…+9 %）。
  准直器散射 2.128e-4，两个 MC 种子 2.144e-4 / 2.111e-4。光电峰窗（MC 1×10⁹）：晶体散射 0.991，准直器散射 0.994。
* 140.5 keV 示例中心体素（MC 共 1×10⁹ 历史，5 个种子/设置）：改进前逐孔 v2/MC 0.90–0.94，改进后整体 0.94；
  各精度参数加倍（孔周 24、沿孔 24、深度 16、入射点 8×8）时结果变化 ≤ 5 %。

### 3. 一阶模型以外的物理（与 `mc_model` / `mc_full` 比较）

| 解析 / MC | 140.5 keV `mc_model` | 140.5 keV `mc_full` | 511 keV `mc_model` | 511 keV `mc_full` |
|---|---|---|---|---|
| PE ↔ primary | 0.94 | 1.12 | 0.75 | 0.96 |
| 晶体散射 | 0.90 | 0.65 | 0.72 | 0.71 |
| 准直器散射 | 0.88 | 0.31 | 0.66 | 0.43 |
| 合计 | 0.94 | 1.09 | 0.73 | 0.79 |
| 散射/主成分（解析 vs MC） | 0.020 vs 0.021 | 0.020 vs 0.046 | 0.22 vs 0.25 | 0.22 vs 0.49 |

（光电峰窗。）一阶模型之外的差别都是物理上真实存在的：

* **同一晶体内的多次相互作用**：MC 的 primary 包含“先康普顿、再光电”的全能量事件，解析 PE 只计
  “首次相互作用即光电”。NaI 在 140.5 keV 时 μ_C/μ = 0.16，多出约 6 %；LYSO 在 511 keV 时 μ_C/μ = 0.67，
  多出 34 %（解析 PE 低估 511 keV 光电峰效率约 25 %）。同样的原因也让散射光子在探测晶体中的全能量吸收
  多于“首次即光电”。
* **多次散射**（以及散射光子在探测晶体内的多次相互作用）：`mc_model` 比 `mc_single` 多 8 %（140.5 keV 光电峰窗）、
  13–14 %（140.5 keV 宽窗）、38–50 %（511 keV 光电峰窗）。
* **瑞利散射**：钨中的瑞利散射不改变能量、留在光电峰窗内，`mc_full` 的准直器散射因此是 `mc_model` 的
  2.9 倍（140.5 keV）/ 1.6 倍（511 keV）。
* **K 荧光**：2.3 mm NaI 像素中碘 K X 射线（28–33 keV）逃逸，140.5 keV 光电峰减少 16 %（MC 能谱 100–120 keV
  的 primary 计数为光电峰的 16.7 %，关闭荧光时为 0）；晶体间的 K X 射线串扰也算入 `xtalscatter`。
* 20 % 能窗、10 % FWHM 时光电峰在窗内的比例为 0.98（511 keV、12 % FWHM 时 0.95），MC 已计入，
  解析 PE 未计（解析散射项计入了）。

完整表格见 [`reference_cpu/report_tc99m.md`](reference_cpu/report_tc99m.md)、
[`reference_cpu/report_511.md`](reference_cpu/report_511.md)；各分量的探测器图像（对所有体素求和，每幅按自身
最小–最大值着色）见 [`reference_cpu/flood_tc99m.png`](reference_cpu/flood_tc99m.png)、
[`reference_cpu/flood_511.png`](reference_cpu/flood_511.png)。在 GPU 上运行后可与之对照。

### 4. 计算量

CPU（4 核）上本例（256 晶体 × 256 体素 × 9 孔）：

| | 140.5 keV 光电峰窗 | 140.5 keV 宽窗 | 511 keV 光电峰窗 | 511 keV 宽窗 |
|---|---|---|---|---|
| 晶体散射 | 206 s | 244 s | 2012 s | 6947 s |
| 准直器散射 | 1938 s | 3469 s | 3987 s | 4806 s |

上一版 v2 为晶体散射 20 / 20 / 130 / 608 s、准直器散射 810 / 809 / 1310 / 1880 s，原来的内核约 20 s。
晶体散射变慢主要因为近邻晶体的表面分成数百个 ≤ 0.1 rad 的小格，且远处晶体至少取 2×2 个横向散射点；
准直器散射变慢因为每个面的 16 个小格各自计算角度、能量、能窗、弦长（原来 16 个入射点只算弦长与遮挡），
以及板体网格 24×24。v2 的准直器散射每个 (晶体, 体素, 孔) 计算约 650 个壳层散射点，入射权重低于最大值
10⁻⁵ 的点跳过；在 GPU 上按同样的网格并行（每线程 179–208 寄存器，无溢出，16×16 线程块）。
需要更快时可在编译时放宽（`-D`）：`S2_CELL_ANG=0.15f`（晶体散射约快 1.6 倍，近邻低约 0.6 %）、
`S2_XT_MIN=1`（远处晶体对低 5–9 %，总量 −0.1 %）、`S2_BK_N=16`（板体 +0.9 %）。

### 5. 结论

* PE 内核本身正确（1 %，加密后 0.4 %）；但它定义的是“首次相互作用即光电”，511 keV 时比真实光电峰效率
  低约 25 %，140.5 keV 小像素 NaI 还有碘逃逸（−16 %）。需要绝对效率时请用 MC 的 primary。
* 散射模型 v2 与同样物理定义的一阶 MC 一致：晶体散射 ≤ 3 %（511 keV ≤ 1 %；140.5 keV 中约 1.3 % 来自 PE
  矩阵），准直器散射 ≤ 5 %（140.5 keV 在 MC 噪声 ±4 % 内，511 keV ≤ 1 %）；原内核在本例中偏差为 0.002–24 倍。
* 一阶模型之外（多次散射、瑞利、K 荧光、同晶体多次相互作用）在 511 keV 和钨准直器中很重要：
  `mc_full` 的散射/主成分比约为一阶 MC 的 2.1–2.2 倍（两种能量下都是）。需要这些贡献时用 MC
  （`save_components = 1` 分别输出各分量）。
* MC 用体素中心点源才与解析内核可比；生产计算建议 `source_sampling = uniform`：2 mm 体素时总灵敏度差 < 1 %，
  逐体素 −5 %…+3 %，形状 TVD ≈ 9 %（针孔像被体素尺寸展宽）。
* 准直板边缘：解析模型约定光子从入射窗入射；MC 中屏蔽结构需按实际设置（`shield_outside_collimator`），
  本例准直板覆盖所有视线且用 `absorber`，两者一致。

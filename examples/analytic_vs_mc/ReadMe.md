# 解析模型 vs 蒙特卡洛：系统矩阵分量对比示例

用同一套 `Params_*.dat`，分别用解析模块（`PEGen_RayTracing_CircularHole` + `ScatterGen_RayTracing_CircularHole`）
和 `MCGen_MultiGPU` 计算系统矩阵，并按分量逐项比较：

| 解析模块 | MC 中对应的事件类别 |
|---|---|
| PE（光电，`PE_SysMat_*_v3.sysmat`） | `primary`：未在准直器中散射、首次相互作用就在本晶体中的事件（含本晶体内康普顿后再吸收） |
| 晶体散射（`Scatter_Crystal_SysMat_*`） | `xtalscatter`：先在其它晶体中相互作用、再在本晶体中沉积 |
| 准直器散射（`Scatter_Collimator_SysMat_*`） | `colscatter`：在准直器中发生过散射 |

## 几何

| | 140.5 keV（`tc99m`） | 511 keV（`511`） |
|---|---|---|
| 准直器 | W 板 60×6×60 mm，3×3 圆柱针孔，r = 0.75 mm，间距 12 mm | W 板 60×10×60 mm，孔同左 |
| 晶体 | 16×16 NaI，2.3×6×2.3 mm，间距 2.5 mm，FWHM 10 % | 16×16 LYSO，2.3×10×2.3 mm，间距 2.5 mm，FWHM 12 % |
| 晶体中心到准直器中心 | 30 mm | 30 mm |
| 视野 | 16×1×16 体素，2 mm，位于准直器前 40 mm 的平面 | 同左 |
| 能窗（`Param_Physics[4]=1`） | 126.46–154.56 keV（另算宽窗 60–200 keV） | 459.9–562.1 keV（另算宽窗 250–650 keV） |

准直板比所有 视野→晶体 视线都大，符合解析模型“光子从入射窗进入”的约定；MC 使用
`shield_outside_collimator = absorber`（板外全吸收），两者的屏蔽假设一致。

## 运行

```bash
# 单卡 GPU（默认 GPU 0，可用 GPU=1 指定）。先编译：
#   PEGen_RayTracing_CircularHole/bd, ScatterGen_RayTracing_CircularHole/bd, (cd MCGen_MultiGPU && make)
./run_example.sh tc99m gpu
./run_example.sh 511 gpu

# 没有 GPU：原始解析 CUDA 内核编译成 CPU 版本 (tools/analytic_cpu) + MCGen_CPU（4 核约 10–20 分钟/例）
(cd ../../MCGen_MultiGPU && make cpu)
./run_example.sh tc99m cpu
```

第三个参数为每体素历史数（默认 4×10⁶）。结果在 `run_<case>/`：`report.md`（表格）、`report.json`、
`flood.svg`（各分量对所有体素求和后的探测器图像，解析 vs MC）。

脚本依次运行：

1. `tools/make_demo_params.py` 生成参数；`wide/` 子目录为同一几何、宽能窗的参数。
2. 解析：`PEGen_CircularHole`，`ScatterGen_CircularHole -PE ... -components`（光电峰窗与宽窗各一次）。
3. MC，三组设置（都用 `source_sampling = center`，即体素中心点源，与解析内核一致）：
   * `mc_pe`：`physics = primary_pe`、理想能窗 —— 与解析 PE 模型的物理完全相同，用来检查 PE 内核；
   * `mc_model`：光电 + 康普顿，系数与能量标度（PE ∝ E⁻³、康普顿 ∝ Klein–Nishina）取自参数文件，
     无瑞利、无荧光 —— 解析散射模型假设的物理，差别只来自解析模型的几何/角度近似；
   * `mc_full`：材料库截面 + 瑞利散射 + K 荧光 —— 真实物理。
4. `compare_components.py` 输出对比表。

表中各列：Σ 为全部矩阵元素之和；“ratio” 为 解析/MC；“per-voxel ratio” 为逐体素灵敏度比值的中位数与
5 %–95 % 范围；“shape TVD” = ½ Σ|A/ΣA − M/ΣM|，0 表示分布形状相同、1 表示完全不重叠；
“MC noise” 是 MC 统计涨落本身能造成的 TVD 上界。

## 结果

本仓库开发环境没有 GPU：下表由 `./run_example.sh <case> cpu` 得到（原始解析 CUDA 内核编译为 CPU 版本，
与 GPU 结果逐位相同的内核代码；MC 每组 1.0×10⁹ 历史）。Σ 为全部矩阵元素之和（每个发射光子的计数 × 体素数）。

### 1. PE 模型：通过

| `mc_pe`（与解析相同的物理） | 140.5 keV | 511 keV |
|---|---|---|
| 解析 / MC（总和） | 0.987 | 0.998 |
| 逐体素比值 中位数 [5 %, 95 %] | 0.990 [0.962, 1.005] | 0.998 [0.989, 1.006] |
| 形状 TVD（MC 噪声上界） | 0.011 (0.003) | 0.031 (0.031) |

140.5 keV 的 1.3 % 是解析内核的子单元离散（针孔半影）：把晶体子单元从 8×16×8 加密到 24×16×24 后为 0.996。
注意 MC 必须用参数文件的系数：若用材料库（含瑞利散射，`primary_pe` 下瑞利散射也会终止光子），
MC 会低 4.8 %（140.5 keV）/ 17 %（511 keV，主要是 10 mm 钨中的瑞利散射），这不是解析模型的误差。

宽能窗（140.5 keV：60–200 keV；511 keV：250–650 keV）中，解析 / MC：晶体散射 5.4 / 4.8（140.5 keV，model / full）、
6.7 / 9.0（511 keV）；准直器散射 20.7 / 3.3（140.5 keV）、0.15 / 0.12（511 keV）。

### 3. 原因

**PE ↔ primary。** MC 的 primary 包含在同一晶体内“先康普顿、再光电”的多次相互作用全能量事件，解析 PE 只计
“首次相互作用即光电”。NaI 在 140.5 keV 时 μ_C/μ = 0.16，多出约 6 %；LYSO 在 511 keV 时 μ_C/μ = 0.67，
多出 34 %，即在相同物理下解析 PE 低估 511 keV 光电峰效率约 25 %。`mc_full` 在 140.5 keV 又低 16 %：2.3 mm 的 NaI 像素中
碘 K X 射线（28–33 keV）逃逸，事件落到 ~111 keV 逃逸峰（MC 能谱 100–120 keV 的 primary 计数为光电峰的
16.7 %，关闭荧光时为 0）。另外 20 % 能窗、10 % FWHM 时光电峰在窗内的比例为 0.98，MC 已计入、
解析 PE 未计（解析散射项计入了）。

**晶体散射。**
1. 散射点固定在散射晶体中心、探测点在探测晶体中心。平面单层阵列中任意两晶体的中心连线与入射方向都接近 90°，
   散射光子能量约 110 keV（140.5 keV）/ 255 keV（511 keV），全部落在光电峰窗外：140.5 keV 只剩 MC 的 0.15 %，
   511 keV 每一对都被 2σ 判据跳过，结果为 0。真实情况下光子在晶体前部以小角度散射、斜穿进邻近晶体，
   MC 中这部分为 primary 的 1.5 %（140.5 keV）/ 1.7 %（511 keV）。
2. 立体角近似：θ 范围取自探测晶体 8 个顶点，φ 范围用包围球半径（含晶体厚度），厚度被计入两次。
   数值检验（2.3×6×2.3 mm NaI，散射点在晶体中心，入射沿 +y，按 Klein–Nishina 加权）：最近邻 0.190 vs 解析 0.381
   （2.0×），对角邻 0.091 vs 0.248（2.7×），次近邻 0.046 vs 0.109（2.4×）；晶体越厚越严重（10 mm LYSO）。
3. 没有计入散射光子在散射晶体自身内（散射点到晶体表面）的衰减。

   因此在宽能窗中解析值高 5–9 倍。

**准直器散射。** 每个孔在孔中心放一个“虚拟面积” (πr_v² + T·r_v)（r_v = 0.1 mm）乘 μ_C/μ 作为散射源，散射光子
在钨中不衰减。
* 140.5 keV（μT = 20，钨不透明）：真正能出来的散射只发生在孔壁薄层里，且散射光子大多被钨吸收，解析高 20 倍
  （只比康普顿）；`mc_full` 的准直器散射是 `mc_model` 的 2.9 倍，多出的部分主要是钨中的瑞利散射（能量不变、
  留在窗内，解析模型没有），比值降为 7 倍。
* 511 keV（μT = 2.4，整块板透射 9 %）：整个板体内的前向康普顿散射占主导，解析只在孔处放散射源，低 5–8 倍。

### 4. 结论与建议

* PE 内核本身正确（1 %、加密后 0.4 %）；但它定义的是“首次相互作用即光电”，511 keV 时比真实光电峰效率低约 25 %，
  140.5 keV 小像素 NaI 还有碘逃逸（−16 %）。需要绝对效率时请用 MC 的 primary。
* 两个解析散射项在本例中量级不可靠：光电峰窗中的晶体散射几乎为 0，准直器散射在 140.5 keV 高 7–20 倍、
  511 keV 低 5–8 倍，散射/主成分比 0.138 vs 0.046（140.5 keV）、0.065 vs 0.485（511 keV）。
  建议散射分量用 MC（`save_components = 1`）。若要改进解析内核：散射点沿入射方向在晶体内按深度积分、
  用矩形的精确立体角、计入散射晶体自吸收；准直器散射需计入散射光子在钨中的衰减和板体内的散射。
* MC 用体素中心点源才与解析内核可比；生产计算建议 `source_sampling = uniform`：2 mm 体素时总灵敏度差 < 1 %，
  逐体素 −5 %…+3 %，形状 TVD ≈ 9 %（针孔像被体素尺寸展宽）。
* 准直板边缘：解析模型约定光子从入射窗入射；MC 中屏蔽结构需按实际设置（`shield_outside_collimator`），
  本例准直板覆盖所有视线且用 `absorber`，两者一致。

能量分辨率随能量的缩放（FWHM/E ∝ E^-1/2）已在三个 ScatterGen 模块中修正；上表即修正后的结果。

# MCGen_MultiGPU configuration - 511 keV annihilation photons (singles, e.g. F-18 SPECT/PET imaging)

# At 511 keV septal penetration and collimator scatter are large and most interactions in the
# crystals are Compton scatters, so the full MC matrix differs most from the analytic one here.

# ---------------------------------------------------------------- energy windows

# ---------------------------------------------------------------- sampling / run

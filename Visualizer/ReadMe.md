# Visualizer — SPECT/PET 元素可视化界面

浏览器中的几何与系统矩阵查看器，零依赖（纯 WebGL2 + Canvas，无需 npm、CDN 或联网），中文 / English 界面。

## 启动

**方式 1 — 直接打开**：双击 `index.html`（`file://`），用“打开文件…/打开目录…”或拖放加载文件，
或点“示例几何”。适合参数文件和不太大的系统矩阵。

**方式 2 — 本地/远程服务器**（推荐用于 GPU 服务器上的大系统矩阵）：

```bash
python3 Visualizer/serve.py --data /path/to/run_dir          # 仅需 Python 标准库
# 浏览器打开 http://127.0.0.1:8765
# 远程服务器：ssh -L 8765:127.0.0.1:8765 user@gpu-server，然后在本机浏览器打开同一地址
```

`serve.py` 默认只监听 127.0.0.1，通过 HTTP Range 和 `/api/strided` 按需读取文件，
GB 级系统矩阵不会整体载入内存；数据目录根下的参数文件、MC 输出会自动加载（子目录中的文件列在左侧，
点击加载）。只接受 Host 为 127.0.0.1 / localhost / [::1] 的请求（防止 DNS rebinding）。
注意：同一台服务器上的其他用户也能连接 127.0.0.1 的端口，数据需保密时不要在多用户机器上运行。

## 可加载的文件

| 文件 | 用途 |
|---|---|
| `Params_Collimator.dat`, `Params_Detector.dat`, `Params_Image.dat`, `Params_Physics.dat` | 几何元素（也接受 `Param_*.dat`；名称需完全一致，打开文件夹时只取最上层的） |
| `*.sysmat` | 解析或 MC 系统矩阵 `[rotation][detector][voxel]`，大小与几何不符时会报错；MC 分段计算的 `*_rotB-E_*.sysmat` 只含旋转 B…E−1，按真实旋转编号显示；`*_relerr.sysmat`（相对误差）不作为矩阵加载 |
| `*_spectrum.csv`, `*_tracks.json`, `*_summary.json` | `MCGen_MultiGPU` 的能谱、光子径迹与运行摘要 |

## 功能

* **3D 视图**：准直器板（半透明）、准直孔（圆柱）、晶体（可按 μ、光电比例、能量分辨率、flag、旋转角、
  深度、编号、所选体素的投影、探测器灵敏度着色）、成像视野（随旋转位置转动）、体素数值点云、
  MC 光子径迹（按能量着色；红=光电、青=康普顿、绿=瑞利、紫=荧光）。
  剖切面 (x/y/z)、正交/透视、预设视角；单击拾取元素，双击以其为中心。
* **布局 x–z**：俯视准直孔排布与晶体足迹，可按准直层过滤，缩放/平移/点选。
* **体素图像**：探测器响应（系统矩阵的一行）或灵敏度图（Σ探测器，流式计算），支持切片、对数、色表；
  单击体素读取该列并把投影显示到晶体上。
* **能谱**：MC 沉积能谱（原发 / 准直器散射 / 晶体间散射），叠加能窗。
* **一致性检查**：层数/孔数与文件长度、孔超出板或未贯穿、孔重叠、晶体重叠（精确旋转矩形测试）、
  晶体与准直器相交、未启用晶体、μ 之和、能量分辨率缺失、视野与准直器碰撞、能窗是否包含 E0、
  系统矩阵大小等。
* **元素信息**：所选晶体/孔/准直层/体素的全部参数（含参数文件原始 y 与加上 FOV2Collimator0 后的世界坐标）。

## 坐标与方向

与计算代码完全一致（已用 `tests/orientation.test.js` 做像素级回归测试）：

* **+y**：从视野指向准直器与探测器（射束方向）；参数文件中的 y 加 `Param_Image[11]`（FOV2Collimator0）为世界坐标。
* **z**：视野旋转轴（轴向）。第 k 个旋转位置的视野绕 +z **逆时针**转 `k × Param_Image[7]`。
* 准直层以 x = z = 0 为中心，孔沿 y 轴；晶体绕 y 轴转 `Param_Detector[11]`：x′ = x cosθ − z sinθ，z′ = x sinθ + z cosθ。

3D 视图右下角的方向指示器随相机转动，坐标轴末端标有 +x/+y/+z，侧栏实时显示“屏幕右 / 上”对应的世界轴。
预设视角都标明视线方向，并与 2D 视图一一对应：

| 预设 | 视线 | 屏幕 → / ↑ | 对应 2D 视图 |
|---|---|---|---|
| 沿 +y | 从视野看向探测器 | +x / +z | 布局 x–z |
| 沿 −y | 从探测器背面看 | −x / +z | 布局 x–z（勾选“从探测器背面看”） |
| 沿 −z | 从 +z 俯视 | +x / +y | 体素图像“物理”方向 |
| 沿 −x | 从 +x 侧看 | +y / +z | — |

“竖直轴”可在 z 与 y 之间切换（轨道旋转绕该轴）。

**体素图像方向**（体素编号 = iz·nX·nY + iy·nX + ix）：

| 模式 | 水平 → | 竖直 | 等同于 |
|---|---|---|---|
| 物理（默认） | x (ix) | y (iy) 向上 | 3D “沿 −z”视角；旋转 0 时探测器在上方 |
| numpy | ix | iy 向下 | `imshow(row.reshape(nZ, nY, nX)[iz])` |
| MATLAB | iy | ix 向下 | `imagesc(reshape(row, nX, nY, nZ)(:,:,iz))` |

图中白色箭头指向当前旋转位置下探测器 (+y) 所在方向（随旋转位置转动：物理与 MATLAB 模式中为顺时针，
numpy 模式中 y 轴向下，为逆时针），左下/左上角标出体素 (0,0)。

## 文件结构

```
index.html, css/style.css
js/util.js      数学、色表、格式化
js/i18n.js      中英文字符串
js/renderer.js  WebGL2 实例化渲染、相机、剖切
js/params.js    参数文件解析、一致性检查、示例几何
js/data.js      本地文件 / HTTP Range 数据源、系统矩阵流式读取
js/plots.js     布局图、体素图像、能谱
js/app.js       界面逻辑
serve.py        数据服务器
tests/orientation.test.js   方向回归测试 (Playwright + Chromium)
```
